UPI Transaction Analysis – Power BI Dashboard

Project Overview

This project analyzes UPI transaction data to identify trends, transaction volumes, failure rates, and user behavior patterns.
The dashboard provides business insights into digital payment performance and transaction efficiency.

Tools & Technologies Used : SQL – Data extraction and transformation, Python – Data cleaning & preprocessing, Power BI – Data modeling, DAX, and dashboard visualization, Excel/CSV – Data source

Key Insights Delivered: Total transaction volume and value analysis, Success vs Failure rate tracking, Bank-wise transaction performance, Daily & Monthly transaction trends, Peak transaction hours analysis, Top performing UPI apps/banks

Dashboard Features: Interactive filters (Date, Bank, Payment Type), KPI Cards (Total Transactions, Total Amount, Success Rate), Trend analysis charts, Drill-down capabilities

Business Impact: Identified high failure rate time windows, Improved monitoring of transaction performance, Enabled data-driven decision-making for digital payments
